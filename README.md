# Marcel Degbe

Bien sûr. Voici un prompt complet prêt à copier-coller dans une IA de création de sites comme Lovable.



Je veux créer un site web d'entraînement au Sprechen B1 en allemand.



OBJECTIF DU SITE

Le site doit permettre à un étudiant de s'entraîner seul au Sprechen B1 avec des thèmes que je fournis dans un PDF.



J'ai fourni un PDF contenant une liste de thèmes B1 ainsi que la correction/modèle correspondant à ces thèmes. Le contenu du PDF doit être utilisé comme base du site. Ne supprime aucun thème et ne modifie pas les corrections originales.



FONCTIONNEMENT PRINCIPAL



1. PAGE D'ACCUEIL



Titre :

"Deutsch Sprechen B1"



Sous-titre :

"Verbessere dein Sprechen mit echten B1-Themen"



Afficher un gros bouton :

"🎲 Zufälliges Thema"



Quand l'utilisateur clique dessus, le site choisit aléatoirement un thème parmi les thèmes présents dans mon PDF.



Ajouter également :

"📚 Alle Themen"



pour permettre de voir tous les thèmes disponibles.



2. PAGE DU THÈME



Après avoir choisi un thème, afficher clairement :



THEMA:

[Nom du thème]



Par exemple :

"Ausbildung"



Le site doit afficher uniquement le thème et les informations nécessaires pour parler.



IMPORTANT :

La correction/modèle du PDF ne doit PAS être visible avant la fin de l'exercice. Elle doit être cachée afin que l'étudiant puisse réellement essayer de parler seul.



3. CHRONOMÈTRE



L'exercice doit être chronométré sur EXACTEMENT 5 MINUTES.



Afficher un grand chronomètre :



05:00



Bouton :

"▶ Start"



Quand l'utilisateur clique sur Start :

- le chronomètre commence à 05:00 ;

- l'enregistrement audio commence ;

- l'utilisateur peut parler librement en allemand ;

- le temps restant doit être visible en permanence.



Le chronomètre descend :



05:00

04:59

04:58

...

00:01

00:00



À 00:00 :

- arrêter automatiquement l'enregistrement ;

- afficher "⏰ Zeit ist vorbei!";

- empêcher l'enregistrement de continuer.



L'utilisateur doit également pouvoir arrêter manuellement avant les 5 minutes avec :

"⏹ Beenden"



4. ENREGISTREMENT AUDIO



Ajouter un bouton :



"🎤 Aufnahme starten"



Pendant l'enregistrement :

"🔴 Aufnahme läuft..."



L'utilisateur doit pouvoir enregistrer sa réponse directement depuis son téléphone ou son ordinateur.



Le site doit demander l'autorisation d'utiliser le microphone si nécessaire.



Après l'enregistrement :

- permettre de réécouter la réponse ;

- afficher un bouton "🤖 Antwort analysieren".



5. ANALYSE IA



Après l'exercice, l'IA doit analyser la réponse orale de l'utilisateur.



L'analyse doit être adaptée au niveau B1.



Afficher les catégories suivantes :



📊 Bewertung



- Grammatik

- Wortschatz

- Aussprache

- Flüssigkeit

- Struktur

- Inhalt



Donner une note pour chaque catégorie et une note globale.



Exemple :



Grammatik: 78/100

Wortschatz: 82/100

Aussprache: 75/100

Flüssigkeit: 80/100

Struktur: 85/100

Inhalt: 80/100



Gesamtnote: 80/100



L'IA doit ensuite expliquer clairement les erreurs.



Format :



❌ "Ich habe viele Erfahrung."



✅ "Ich habe viel Erfahrung."



Explication :

"Erfahrung" est normalement indénombrable dans cette expression, donc on utilise "viel Erfahrung".



6. AMÉLIORATION DE LA RÉPONSE



Après la correction, l'IA doit proposer une version améliorée de la réponse de l'utilisateur.



IMPORTANT :

La version améliorée doit rester au niveau B1 et ne doit pas devenir artificiellement trop compliquée.



Afficher :



"✨ So kannst du es besser sagen:"



Puis la version améliorée.



7. CORRECTION DU PDF



Ajouter un bouton :



"📖 Musterlösung anzeigen"



Ce bouton affiche ensuite la correction correspondant exactement au thème choisi dans mon PDF.



Par exemple, si le thème choisi est "Ausbildung", afficher la correction de "Ausbildung" présente dans mon document.



Ne pas remplacer cette correction par une nouvelle réponse inventée par l'IA.



La correction originale du PDF doit rester clairement identifiable comme :

"📖 Originale Musterlösung"



8. COMPARAISON



Après avoir affiché la correction, permettre à l'utilisateur de comparer :



"🗣️ Meine Antwort"

avec

"📖 Musterlösung"



L'IA peut ensuite expliquer :

- quels arguments l'utilisateur a utilisés ;

- quels arguments importants il a oubliés ;

- quelles expressions intéressantes il pourrait réutiliser ;

- quelles erreurs il doit éviter.



9. LISTE DES THÈMES



Créer une page :



"📚 Alle Themen"



Afficher tous les thèmes présents dans mon PDF.



Les thèmes doivent être récupérés du document fourni.



L'utilisateur peut cliquer sur un thème pour commencer directement l'exercice.



Ajouter une recherche :



"🔍 Thema suchen..."



10. THÈME ALÉATOIRE



Le bouton "🎲 Zufälliges Thema" doit choisir réellement un thème au hasard parmi tous les thèmes disponibles.



Éviter de sélectionner toujours les mêmes thèmes.



Si possible, mémoriser les thèmes déjà pratiqués afin de favoriser les thèmes que l'utilisateur n'a pas encore travaillés récemment.



11. HISTORIQUE



Créer une petite section :



"📈 Mein Fortschritt"



Elle doit afficher :

- nombre de thèmes pratiqués ;

- nombre d'exercices réalisés ;

- score moyen ;

- derniers thèmes travaillés.



Exemple :



Themen geübt: 12

Durchschnitt: 78/100



12. DESIGN



Le site doit être :

- moderne ;

- simple ;

- très clair ;

- adapté à un étudiant ;

- parfaitement utilisable sur téléphone Android ;

- responsive sur ordinateur, tablette et téléphone.



L'interface doit être principalement en allemand puisque l'objectif est de pratiquer l'allemand.



Utiliser une présentation propre avec de gros boutons faciles à toucher sur téléphone.



13. STRUCTURE DU SITE



Créer au minimum :



🏠 Startseite

🎲 Zufälliges Thema

📚 Alle Themen

📈 Mein Fortschritt



14. IMPORTANT : CONTENU DU PDF



Le PDF que j'ai fourni est la source principale des thèmes et des corrections.



Il contient notamment des thèmes comme :

Ausbildung, Auslandsaufenthalt, Behinderten-Sport, Berufstätige Eltern, Berufswahl, Bio-Essen, Chatten, Computer für jeden Kursraum, Das Internet, Einkaufen in Einkaufszentren, Einkaufen im Internet, Extremsport, Facebook, Fertigessen, Freiwillige Arbeiten, Freundschaft, Gebrauchte Kleidung, Haustiere, Heiraten, Hotel Mama, Informationen im Internet, Kinder und Fernsehen, Kinder und Handys, Kinos sterben, Kreditkarten, Leben auf dem Land oder in der Stadt, Makeup für die Kinder, Marken-Kleidung, Mode, Reisen, Sport treiben, Sprachenlernen, Studium, Tattoos, Teilzeitarbeit, Unsere Idole, Umweltschutz, Vegetarische Ernährung et Zeitungsleser.



Le document contient également les corrections/modèles associés à plusieurs de ces thèmes.



IMPORTANTE RÈGLE :

Utiliser le contenu réellement présent dans le PDF comme source. Ne pas inventer de corrections qui ne sont pas dans le document.



15. EXPÉRIENCE UTILISATEUR



Le parcours doit être très simple :



Accueil

↓

🎲 Zufälliges Thema

↓

Thema affiché

↓

▶ Start

↓

⏱️ 5 minutes

↓

🎤 Réponse enregistrée

↓

🤖 Analyse IA

↓

📊 Note + corrections

↓

📖 Musterlösung

↓

🔄 Neues Thema



16. TECHNOLOGIE



Construire un véritable site web fonctionnel, pas seulement une maquette visuelle.



Le microphone et l'enregistrement doivent fonctionner réellement.



Le chronomètre de 5 minutes doit fonctionner réellement.



L'analyse IA doit être prévue avec une architecture permettant de connecter une API d'intelligence artificielle.



Prévoir une architecture propre et facilement extensible.
